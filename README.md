# Найкраща Кава — веб-додаток кав'ярні

Курсовий проєкт з дисципліни «WEB-технології та WEB-дизайн».
Веб-сайт кав'ярні з онлайн-меню, сторінками позицій, бронюванням столиків, особистим кабінетом і панеллю адміністратора.

**Технології:** Python 3, Flask, Jinja2, HTML5, CSS3 (Grid, Flexbox), JavaScript (ES6+). Далі — SQLite.

## Запуск локально

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
python app.py
```

Відкрити в браузері: http://127.0.0.1:5000

## Сторінки

| Адреса | Сторінка |
|---|---|
| `/` | Головна (Hero + популярні позиції) |
| `/menu` | Каталог меню: фільтр за категоріями, сортування, пошук |
| `/menu/<id>` | Сторінка позиції меню |
| `/booking` | Форма бронювання столика (валідація на клієнті й сервері) |
| `/account` | Вхід / реєстрація та «Мої бронювання» |
| `/admin` | Панель адміністратора: таблиця позицій, видалення з модальним вікном |

## Структура

```
app.py            маршрути Flask
data.py           тимчасові дані (буде замінено на SQLite)
templates/        шаблони Jinja2 (base.html + сторінки)
static/css/       стилі
static/js/        клієнтські скрипти
static/img/       зображення
```
